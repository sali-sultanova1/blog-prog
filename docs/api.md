# REST API

API реализовано на Django REST Framework.

Интерактивная документация доступна в Swagger:

```text
/api/docs/
```

OpenAPI schema:

```text
/api/schema/
```

## Аутентификация

Для API используется JWT.

Получение токена:

```text
POST /api/token/
```

Обновление access token:

```text
POST /api/token/refresh/
```

Также поддерживается session authentication.

## Основные endpoints

### Статьи

```text
GET    /api/articles/
GET    /api/articles/{id}/
POST   /api/articles/
PATCH  /api/articles/{id}/
PUT    /api/articles/{id}/
DELETE /api/articles/{id}/
```

Публичный список содержит только опубликованные статьи.

Создавать статьи через API может пользователь с правом `add_article`. Новая статья всегда создаётся как черновик независимо от переданного клиентом статуса.

Изменять собственную статью можно только в статусе `draft` или `rejected`.

Дополнительные actions:

```text
POST /api/articles/{id}/like/
POST /api/articles/{id}/bookmark/
```

Они доступны только авторизованным пользователям и работают только с опубликованными статьями.

### Комментарии

```text
GET    /api/comments/
POST   /api/comments/
GET    /api/comments/{id}/
PATCH  /api/comments/{id}/
DELETE /api/comments/{id}/
```

Создавать комментарии могут только авторизованные пользователи и только к опубликованным статьям.

Редактировать и удалять комментарий может только его автор.

### Категории

```text
/api/categories/
```

### Теги

```text
/api/tags/
```

Чтение категорий и тегов доступно всем. Изменение доступно только staff-пользователям.

## Поиск, фильтрация и сортировка

Для статей поддерживаются:

- поиск по заголовку, краткому описанию, содержанию, автору и тегам;
- фильтрация по категории;
- фильтрация по тегу;
- сортировка по дате публикации, дате создания и заголовку;
- пагинация.

Для комментариев доступны фильтрация по статье, поиск и сортировка по датам.

## Дополнительные возможности

### Фильтрация и сортировка

GET /api/articles/?author=5&status=published&ordering=-updated_at

Параметр author — ID пользователя. Публичный список содержит только опубликованные статьи.

### Собственные статьи

GET /api/articles/mine/?status=draft

Требуется вход через JWT или сессию. Возвращаются только собственные статьи пользователя. Поддерживаются фильтры, сортировка и пагинация.

### Снятие с публикации

POST /api/articles/{id}/unpublish/

Доступно автору с правом изменения своей статьи или сотруднику сайта.

Статья возвращается в черновики. Действие сохраняется в истории. Повторная публикация требует модерации.

Успешный ответ: 200.
Неверное состояние статьи: 409.

Регистрация выполняется через HTML-форму с подтверждением email. Отдельной регистрации через API нет.
