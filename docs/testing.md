# Тестирование

В проекте используется встроенная система тестирования Django и инструменты Django REST Framework.

Всего предусмотрено 43 автоматических теста.

## Что проверяется

### Аутентификация

Проверяется вход:

- по username;
- по email.

### Web-логика статей

Проверяются основные правила приложения:

- публично отображаются только опубликованные статьи;
- черновик недоступен гостю;
- обычный пользователь не может создавать статьи;
- пользователь может стать автором;
- автор может отправить черновик на модерацию;
- staff-пользователь может опубликовать статью;
- профиль автора недоступен гостю.

### REST API

Проверяются:

- публичный список опубликованных статей;
- создание черновика автором;
- запрет создания статьи обычному пользователю;
- запрет редактирования опубликованной статьи;
- редактирование собственного черновика;
- лайки;
- закладки;
- создание комментария;
- запрет комментариев для гостя;
- запрет комментариев к черновику;
- запрет изменения чужого комментария.

### Unit-тесты

Отдельно проверяется валидация комментариев: комментарий разрешён только для опубликованной статьи.

### Системный тест

Есть тест полного сценария публикации:

```text
пользователь
→ становится автором
→ создаёт черновик
→ отправляет на модерацию
→ staff публикует статью
→ статья становится доступна публично
```

## Запуск

Полный набор тестов:

```bash
docker compose exec web python manage.py test
```

Проверка конфигурации Django:

```bash
docker compose exec web python manage.py check
```

Проверка отсутствия неприменённых изменений моделей:

```bash
docker compose exec web python manage.py makemigrations --check --dry-run
```

GitHub Actions запускает тесты автоматически при `push` и `pull_request`.
